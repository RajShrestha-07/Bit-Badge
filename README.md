# Bit Badge
Bit Badge is a small web app that shows how text is stored as binary. Type a word and it displays the binary code for each character. You can copy the binary output, or flip individual bits to see how the text changes.
Live demo: https://rajshrestha-07.github.io/Bit-Badge/
Built with:HTML, CSS and JavaScript
What I learned: Building Bit Badge taught me how computers store text. Every character is a number (its ASCII or Unicode code), and that number is stored as 8 binary digits (bits). I learned how to convert text to binary and back using JavaScript, and how flipping a single bit can change one letter into a completely different one. I also practised handling user input, updating the page as the user types, and adding a copy-to-clipboard button.
